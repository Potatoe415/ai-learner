# 0004 — English-first interface, French later

Date: 2026-11-10
Status: Accepted
Decision: Ship the interface and courses in English first and add French afterwards.
Context: The Claude Design canvas is in English; the user also plans French content.

Alternatives_Rejected: French first (translate the design now). Bilingual from the start (more work before any content exists).
